# RideLink

RideLink is a Flask-based carpool management platform that helps commuters find and join shared rides.

## Features

- User authentication
- Create carpool routes
- Find nearby groups
- Join ride pools
- Dashboard analytics

## Technologies

- Python
- Flask
- SQLite
- Bootstrap
- HTML/CSS

## Setup

Install dependencies:

pip install -r requirements.txt

Create database:

python init_database.py

Run:

python app.py
